# Prompt para o Codex — Versão de Aula do GameVerse

## Contexto

O repositório já contém a versão final e completa do projeto **GameVerse**. Agora, crie uma nova pasta destinada exclusivamente às aulas do curso de Front-End.

Essa nova pasta servirá como material de apoio para o professor acompanhar a evolução do projeto ao longo das aulas.

Atualmente, as aulas 1 e 2 já foram concluídas e a próxima aula será a aula 3.

---

## Objetivo

Criar uma pasta chamada:

```text
aulas/
```

Dentro dela, organizar versões simplificadas e progressivas do projeto.

Exemplo:

```text
aulas/
├── aula-01/
├── aula-02/
├── aula-03/
└── README.md
```

---

## Regras importantes

- Não modificar a versão final do GameVerse.
- A pasta `aulas/` deve funcionar como uma linha do tempo do projeto.
- Cada aula deve representar exatamente o estado do projeto ao final daquele encontro.
- O código precisa ser simples, didático e fácil de explicar.
- Evitar antecipar conteúdos que ainda não foram ensinados.

---

# Situação atual do curso

## Aula 1 — Primeira página e introdução à Web

Já aconteceu.

A pasta `aula-01` deve conter apenas:

- Estrutura básica do HTML.
- Título da página.
- Cabeçalhos.
- Parágrafos.
- Primeiras imagens.
- Conteúdo introdutório sobre videogames.
- Estrutura mínima de pastas.

Ainda não deve existir:

- CSS complexo.
- Navegação.
- Componentes.
- Layouts.

---

## Aula 2 — Organização de conteúdo e tipografia

Já aconteceu.

A pasta `aula-02` deve incluir a evolução da aula anterior com:

- Arquivo CSS separado.
- Tipografia.
- Hierarquia visual.
- Seções organizadas.
- Listas.
- Ajustes básicos de espaçamento.
- Melhor organização do conteúdo.

Ainda não deve existir:

- Navegação completa.
- Menus sofisticados.
- Layouts com Flexbox.
- Bootstrap.

---

## Aula 3 — Links e navegação

Será a próxima aula.

A pasta `aula-03` deve representar exatamente o ponto em que o professor começará a aula.

Ela deve partir da estrutura da aula 2 e adicionar:

- Menu de navegação.
- Links internos.
- Links entre páginas.
- Organização inicial das páginas:
  - Home
  - Notícias
  - Galeria
  - Contato
- Estados `hover`.
- Destaque visual para links.
- Estrutura simples e didática.

Importante:

- Não utilizar Flexbox ainda.
- Não utilizar Grid.
- Não utilizar Bootstrap.
- Não adicionar recursos de aulas futuras.

# README da pasta aulas

Criar um arquivo:

```text
aulas/README.md
```

Esse arquivo será utilizado pelo professor como guia durante as aulas.

O README deve conter:

## Apresentação

Explicar que a pasta contém a evolução do projeto GameVerse ao longo do curso.

## Estrutura

Descrever a finalidade de cada pasta.

## Objetivo pedagógico

Explicar que:

- cada aula adiciona novos recursos;
- os conteúdos acompanham a progressão do módulo;
- o foco está no aprendizado baseado em projetos;
- o projeto final surge gradualmente.

## Relação entre as aulas

Criar uma tabela semelhante a:

| Aula | Tema |
|-------|-------|
| 1 | Primeira página e introdução à Web |
| 2 | Organização de conteúdo e tipografia |
| 3 | Links e navegação |

Adicionar um espaço preparado para as próximas aulas.

## Orientações para o professor

Incluir recomendações como:

- evitar copiar código pronto;
- escrever o código durante a aula;
- incentivar adaptações;
- mostrar erros comuns;
- comparar a versão da aula com a versão final do projeto.

---

## Qualidade esperada

O material deve parecer um projeto educacional oficial:

- organizado;
- fácil de navegar;
- didático;
- incremental;
- consistente com a versão final do GameVerse;
- preparado para futuras aulas.
